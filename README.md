# Симулятор геометрического горения зарядов РДТТ

Программа строит график площади поверхности горения `Sг(e)` и показывает
анимацию регрессии фронта для четырёх форм:

- торцевое горение;
- цилиндрический канал;
- звездообразный канал;
- щелевой заряд.

Поддерживаются скреплённый заряд (наружная поверхность забронирована) и
вкладной заряд (наружная поверхность горит). Формулы звездообразного и
щелевого зарядов воспроизводят методичку «Топливные заряды РДТТ 2022».

## Запуск интерфейса

На macOS с системным Python нужные библиотеки обычно уже доступны:

```bash
python3 app.py
```

Если библиотек нет:

```bash
python3 -m pip install -r requirements.txt
python3 app.py
```

В окне выберите форму и способ установки, измените размеры и нажмите
«Рассчитать». Анимация в интерфейсе воспроизводится с частотой 60 кадров/с.
Кнопки экспорта сохраняют текущий график в PNG и полную анимацию в GIF.
Фактическая частота GIF может округляться просмотрщиком из-за ограничений
формата; расчёт и интерактивное воспроизведение используют 60 FPS.
Ползунок `Скорость анимации` позволяет менять темп от 0,25× до 4× без
повторного расчёта. Выбранный множитель учитывается и при экспорте GIF.

Поля параметров звезды отображаются только для звездообразного канала, а
поля количества, глубины и ширины щелей — только для щелевого заряда.
Щелевая анимация показывает два сечения: зону щелей и торцевой фронт. После
выгорания щелей торцевой фронт остаётся видимым до конца расчёта.

Для быстрого запуска дважды щёлкните `Запустить симулятор.command` в Finder.

Для цилиндрического заряда диаметр канала задаётся напрямую в поле
`Диаметр канала d, мм`. Физический свод автоматически вычисляется как
`(D - d) / 2`; значение поля свода для этой формы не используется.

## Пакетный экспорт

```bash
python3 -m grain_burner.export_demo --shape star --installation bonded
```

Пример цилиндрического канала диаметром 100 мм:

```bash
python3 -m grain_burner.export_demo --shape cylinder --channel-diameter 100
```

Формы для `--shape`: `end`, `cylinder`, `star`, `slot`; варианты установки:
`bonded`, `free`. Результаты появляются в `output/` в виде PNG, GIF и JSON.

## Марки топлива

Наборы находятся в `grain_burner/fuels.json`. Плотность влияет на расчётную
массу, а постоянная скорость горения задаёт временной масштаб анимации:

```json
"Моя марка": {
  "density_kg_m3": 1720.0,
  "burn_rate_mm_s": 7.4,
  "note": "Паспортные данные при выбранном рабочем давлении"
}
```

Встроенные марки, кроме плотности 1750 кг/м³ из тестовой задачи методички,
являются демонстрационными. Для инженерного расчёта замените их паспортными
данными и скоростью при требуемом давлении. Закон `u(p, T)` пока не решает
внутреннюю баллистику; используется постоянная скорость `u`.

## Принятые допущения

- Торцы цилиндрического и звездообразного зарядов забронированы.
- Для щелевого заряда один торец открыт, второй забронирован — как в методичке.
- Вкладной цилиндрический заряд считается точно до полного выгорания.
- Вкладные звездообразный и щелевой заряды рассчитываются до первого
  смыкания внутреннего и наружного фронтов. Догорание разобщённых остатков
  требует отдельной модели.
- Анимация сложных каналов строится численным смещением контура; график
  `Sг(e)` строится по аналитическим формулам методички.

## Проверка

```bash
python3 -m unittest discover -s tests -v
```

Тесты проверяют контрольные значения приложений методички, включая
`Sср = 0.634921 м²` для щелевого заряда и `Sср = 0.941992 м²` для звезды.
